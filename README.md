## About

A single-page portfolio built with vanilla HTML, CSS, and JavaScript — no frameworks, no build tools, no dependencies. Everything runs in the browser.

**Highlights:**
- 🎵 Generative lo-fi music via Web Audio API (5 original tracks)
- ✨ Canvas particle background with mouse repulsion
- 🖱️ Custom animated cursor with trailing ring
- 📜 Scroll-reveal animations with Intersection Observer
- 📱 Fully responsive
